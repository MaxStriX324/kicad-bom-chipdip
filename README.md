# KiCad BOM → ChipDip — v6

Программа переводит **любой CSV-экспорт KiCad** в **один основной TXT с полным составом**. Главный результат — `ИМЯ_chipdip.txt`: в нём каждая собираемая позиция BOM учтена в формате `обозначение<TAB>количество`. Имя файла задаётся именем исходной спецификации, а не `EVSE`.

Основной TXT объединяет известные артикула и поисковые описания для неопределённых позиций. **Это полный список для поиска, не автоматически проверенный заказ**. При поиске на сайте ChipDip нужно сверять каждый товар с характеристиками, корпусом и схемой.

## Быстрый запуск Windows

1. Распаковать репозиторий и один раз запустить `install.bat`. Установщик создаёт локальную `.venv`. Если Python 3.9+ отсутствует, он предложит установку через `winget` (интернет нужен только для установки Python).
2. Запустить `start.bat` и выбрать любой CSV из KiCad. Также можно перетащить CSV на `start.bat`.
3. Открыть **`ИМЯ_chipdip.txt` рядом с исходным CSV**. Это полный результат работы программы; ничего объединять вручную не требуется.

## Результаты

- **`ИМЯ_chipdip.txt`** — основной полный TXT с каждым компонентом и количеством.
- `ИМЯ_chipdip_mpn_only.txt` — только артикулы, явно указанные в KiCad или в утверждённом файле соответствий. Для точного заказа требует проверки наличия и корпуса.
- `ИМЯ_search_all.txt` — копия полного TXT для совместимости с версией v5.
- `ИМЯ_chipdip_candidates_only.txt` — возможные артикулы, которые алгоритм распознал по `Value`, но никто не подтвердил.
- `ИМЯ_review.csv` — все исходные поля KiCad, причины и результаты классификации.
- `ИМЯ_needs_review.csv` — элементы, по которым требуется уточнение исполнения или электрических параметров.
- `ИМЯ_mapping_template.csv` — шаблон для сохранения выбранных артикулов.
- `ИМЯ_summary.txt` — контроль количества и статус подбора.

Конвертер контролирует равенство суммы количества элементов в основном TXT и BOM. Исключённые в KiCad компоненты `DNP` и `Exclude from BOM` в закупку не входят.

## Автоматическое сопоставление артикулов

Для конкретной платы положите **рядом с исходным CSV** файл с именем `ИМЯ_mapping.csv` (например, для `Моя плата.csv` — `Моя плата_mapping.csv`). Программа автоматически найдёт его и учтёт указанные `PartNumber`; отдельно запускать ничего не требуется.

Простейшее содержимое CSV (разделитель `;`):

```csv
Reference;PartNumber
TP1;TEST-PCB-A-R-01
TP2;TEST-PCB-A-R-01
```

Это **проектное** соответствие: оно не используется для других плат, если только вы отдельно не добавите такой файл соответствий. Выбранные TP1–TP13 для платы EVSE пример сопоставления, но **геометрия отверстий и доступность в ChipDip пока не подтверждены**. Не добавляйте этот артикул без проверки в другие проекты.

При отсутствии файла сопоставлений программа **всё равно выдаёт полный TXT** — неопределённые позиции получают поисковые описания. Если вы заполнили автоматически созданный `ИМЯ_mapping_template.csv`, при следующем запуске его тоже можно прочитать автоматически (либо передать путь с `--mapping`). Приоритет: `ИМЯ_mapping.csv` → `ИМЯ_mapping_template.csv`.

## Дополнительные параметры

```powershell
python kicad_bom_chipdip.py "C:\BOM\Моя плата (1).csv"
python kicad_bom_chipdip.py "C:\BOM\Моя плата (1).csv" --boards 3
python kicad_bom_chipdip.py "C:\BOM\Моя плата (1).csv" --mapping "C:\BOM\selected.csv"
python kicad_bom_chipdip.py "C:\BOM\Моя плата (1).csv" --no-auto-mapping
python -m unittest discover -s tests -v
```

`settings.json`:

```json
{
  "boards": 1,
  "include_nominals": false,
  "mapping_file": "",
  "output_dir": "",
  "auto_mapping": true
}
```

В `MP`, `MPN`, `ChipDip` можно записать артикул непосредственно в KiCad. Программа берёт его в первую очередь. Код использует Python 3.9+ и стандартную библиотеку; сторонних библиотек и API ChipDip нет.
