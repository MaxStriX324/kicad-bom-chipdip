# KiCad BOM → ChipDip

Автономный конвертер спецификаций KiCad (CSV) в поисковый список для **ЧИП и ДИП**. Основной TXT включает **все компоненты**, даже если в KiCad указан только номинал или посадочное место. Неоднозначные записи предназначены для поиска и ручного выбора товара, а не автоматического заказа.

## Возможности

- Читает стандартные столбцы KiCad `Reference, Qty, Value, DNP, Exclude from BOM, Footprint` и любые дополнительные колонки (например, `MP`, `MF`, `MANUFACTURER`, `Описание`).
- Суммирует одинаковые артикулы и корректно обрабатывает сгруппированные обозначения (`C1,C2,C3`).
- Умножает количество на число собираемых плат через `--boards`.
- Исключает DNP и `Exclude from BOM`.
- Приоритет точности: поля `ChipDip` / `MPN` / `MP` в BOM → таблица сопоставления → распознанное обозначение из `Value`.
- Не выдаёт обычный номинал `100nF` или `1k` за конкретный товарный артикул: формирует поисковую фразу вида `100nF 0805`.
- Формирует таблицу для ручной проверки и шаблон соответствий для последующих проектов.
- Не требует внешних библиотек и интернета. Python 3.9+.
- Поддерживает `settings.json`: количество плат, режим поиска по номиналам, файл соответствий и каталог результатов.

## Быстрый запуск в Windows

1. Распакуйте ZIP с GitHub и один раз запустите **`install.bat`**. Он создаст локальную `.venv` рядом с проектом, проверит Python 3.9+, а при необходимости попробует установку через winget для текущего пользователя (без прав администратора). Сторонние Python-библиотеки не требуются.
2. Двойной клик на **`start.bat`** — выберите **любой** KiCad CSV через окно проводника. Также можно перетащить CSV на `start.bat`. Если Tkinter недоступен, путь можно ввести в консоли.
3. Получите файлы в папке со спецификацией под **именем исходного файла**:
   - `ИМЯ_chipdip.txt` — **полный поисковый список**, каждая позиция BOM учтена (`запрос<TAB>количество`);
   - `ИМЯ_chipdip_candidates_only.txt` — **отдельный сокращённый список** с распознанными артикулами/кандидатами;
   - `ИМЯ_review.csv` — результаты и предупреждения по каждой позиции;
   - `ИМЯ_mapping_template.csv` — шаблон соответствий, который можно заполнить точными артикулами;
   - `ИМЯ_summary.txt` — числовой отчёт.
4. Скопируйте содержимое `*_chipdip.txt` в форму поиска по списку на сайте ChipDip. Сверьте найденные товары с исходной спецификацией. **Наличие строки в TXT не означает, что найден подходящий товар.**

## Работа через консоль

```powershell
python kicad_bom_chipdip.py "C:\BOM\Любое имя спецификации (1).csv"
python kicad_bom_chipdip.py "C:\BOM\Любое имя спецификации (1).csv" --boards 5
python kicad_bom_chipdip.py "C:\BOM\Любое имя спецификации (1).csv" --mapping "C:\BOM\Любое имя спецификации (1)_mapping_template.csv"
python kicad_bom_chipdip.py "C:\BOM\Любое имя спецификации (1).csv" --include-nominals
python -m unittest discover -s tests -v
```

`--include-nominals` оставлен для совместимости с прежней классификацией и отдельным списком кандидатов. В основной полный TXT номиналы попадают всегда, например `100nF 0805`. **Поисковые фразы не являются артикулами и не образуют готовый заказ.**

## Настройки

Отредактируйте `settings.json` рядом со скриптом:

```json
{
  "boards": 1,
  "include_nominals": false,
  "mapping_file": "",
  "output_dir": ""
}
```

Пустые `mapping_file` и `output_dir` означают отсутствие файла сопоставлений
и сохранение результата рядом с исходным CSV. Аргументы командной строки
перекрывают соответствующие настройки. Рекомендуется указывать
`mapping_file` после первого заполнения таблицы артикулов.

## Сопоставление точных артикулов

Откройте `ИМЯ_mapping_template.csv` в Excel или текстовом редакторе.
Найдите строки, которые требуют подбора, и заполните столбец `PartNumber`,
не меняя `Reference`, `Value`, `Footprint`. Перезапустите с `--mapping`.
Поиск идёт в порядке: полная группа `Reference`, отдельные обозначения
(если все в группе сопоставлены одинаково), затем пара `Value+Footprint`.

В собственном BOM KiCad можно сразу добавить колонки `MPN`, `MP` или `ChipDip` —
они используются в первую очередь без внешнего файла сопоставлений.

Важно: обозначения вроде `BC817`, `SS14`, `LM7332` могут соответствовать
нескольким производителям, корпусам или исполнениям. Они включаются
как поисковые **кандидаты**, но требуют проверки перед закупкой. Обозначения
с `x` как незаданным символом (`STM32F405VGTx`) нельзя считать точным MPN.

## Техническое устройство

Один файл `kicad_bom_chipdip.py`, не зависимый от Windows. `install.bat`
создаёт локальную среду Windows (`.venv`), `start.bat` запускает её.
Отчёт `*_review.csv` сохраняет все экспортированные колонки KiCad с префиксом
`KiCad:` и `SearchQuery` — точный поисковый запрос для каждой исходной позиции. Тесты используют `unittest` стандартной библиотеки.
Никаких обращений к API ChipDip и автоматических заказов нет.
